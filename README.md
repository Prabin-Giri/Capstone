# Capstone – Frontend (React + TypeScript + Vite)

Frontend for our Automated Grading System project.

## Tech
- React
- TypeScript
- Vite

## Getting Started

### Requirements
- Node.js (LTS recommended)
- npm (or yarn/pnpm)

### Install
```bash
npm install
```

### Run
```bash
npm run dev
```

### Build
```bash
npm run build
```
